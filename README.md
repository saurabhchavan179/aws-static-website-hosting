# Secure Static Website Hosting on AWS

## 📌 Project Overview

This project demonstrates the deployment of a secure static portfolio website on AWS using Amazon S3, CloudFront, Route 53, and AWS Certificate Manager (ACM).

The website is hosted on Amazon S3 and delivered globally through Amazon CloudFront with HTTPS enabled using an ACM SSL/TLS certificate.

## 🏗️ AWS Architecture

Route 53 → CloudFront → S3

- **Amazon S3** – Hosts the static website files
- **Amazon CloudFront** – Provides CDN and global content delivery
- **AWS Certificate Manager (ACM)** – Provides SSL/TLS certificate
- **Amazon Route 53** – Handles DNS and custom domain routing

## 🛠️ AWS Services Used

- Amazon S3
- Amazon CloudFront
- Amazon Route 53
- AWS Certificate Manager (ACM)

## 🔐 Key Features

- Static website hosting using Amazon S3
- HTTPS/SSL configuration using ACM
- Global content delivery using CloudFront
- Custom domain configuration using Route 53
- Secure web access over HTTPS
